# Shared repository instructions

Read and follow [AGENTS.md](AGENTS.md) before working in this repository. It is
the shared privacy and publication policy for all agents and subagents.

Keep real personal and connection data out of code, fixtures, previews, docs,
assets, logs, and commits. Install the local privacy hooks and run the required
checks described there. Do not bypass a failing check to commit or push.

See [docs/PRIVACY.md](docs/PRIVACY.md) for setup, local private terms, and the
limits of these protections.
